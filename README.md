# Maktab CRM - Xususiy Maktab Boshqaruv Tizimi

Zamonaviy, qulay va to'liq moslashuvchan (Desktop, Planshet, Mobil) xususiy maktab boshqaruv tizimi.

## 🌟 Asosiy imkoniyatlar

1. **Boshqaruv paneli (Dashboard)**: Maktabning asosiy KPI ko'rsatkichlari, qabul voronkasi tahlili, bugungi vazifalar va tadbirlar.
2. **Qabul bo'limi (Leads Kanban)**: 4 bosqichli Kanban doska (*Yangi*, *Bog'lanildi*, *Suhbat*, *Shartnoma*), kartalarni sudrab ko'chirish (Drag-and-Drop) va qo'ng'iroq qilish imkoniyati.
3. **O'quvchilar bazasi (Students)**: Sinflar va qarzdorlik bo'yicha saralash, qidiruv tizimi, o'quvchi to'liq profili va CSV ga yuklash.
4. **Sinflar va o'qituvchilar (Classes & Teachers)**: Sinflar sig'imi, sinf rahbarlari, o'qituvchilar dars yuklamalari va yangi sinf/o'qituvchi qo'shish.
5. **To'lovlar (Payments)**: Oylik tushum, kutilayotgan to'lovlar, qarzdor oilalar hisobi, to'lov qabul qilish va Excel/CSV hisoboti.
6. **Davomat (Attendance)**: Sinflar va repetitorlik guruhlari bo'yicha kunlik davomat belgilash (*Keldi*, *Kelmadi*, *Sababli*).
7. **Hisobotlar (Reports)**: Reklama manbalari (Instagram, Telegram, Sayt, Tavsiya) konversiyasi va moliyaviy grafiklar.

## 🛠 Texnologiyalar

- HTML5, Vanilla CSS3 (Custom Design System)
- JavaScript (ES6+ Modules)
- Vite (Tezkor build va dev server)
- LocalStorage (Ma'lumotlarni saqlash)

## 🚀 Ishga tushirish

```bash
# 1. Kutubxonalarni o'rnatish
npm install

# 2. Loyihani ishga tushirish
npm run dev
```

Brauzerda ochish: `http://localhost:5173/`
